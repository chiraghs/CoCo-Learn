SECTION 2: SYSTEM ARCHITECTURE & SNOWFLAKE COCO INTEGRATION
System Architecture: Governed 5-Tier Snowflake CoCo Foundation
1. Presentation Layer
• Streamlit Command Center: Native in-Snowflake executive dashboard with live risk heatmaps, DOI monitors & 1-click PO mitigation.
• Snowflake CoCo CLI: Terminal & conversational agent interface for real-time querying and automated agent actions.
2. Action MCP Protocol
• FastAPI Action MCP Server: Standardized agentic tools in mcp/supply_chain_mcp.py exposing 5 enterprise tools.
• Transactional Tools: reroute_purchase_order, get_plant_stockout_risk, search_supplier_contracts, simulate_disruption.
3. Cortex AI Dual-Brain
• Snowflake Cortex Analyst: Semantic parser converting human intent into verified deterministic SQL queries.
• Snowflake Cortex Search: Vector search service (SUPPLIER_CONTRACTS_SEARCH) indexing supplier MSAs & SLA clauses.
4. Governance & Dynamic Tables
• Semantic Ontology YAML: supply_chain_semantic_model.yaml defining trusted metrics, dimensions, and joins.
• 1-Minute Dynamic Tables: DT_PLANT_STOCKOUT_RISK, DT_SUPPLIER_PERFORMANCE, DT_ACTIVE_DISRUPTIONS.
5. Unified Relational Data Layer
• Core Schema: 7 relational tables in SUPPLY_CHAIN_DB.CORE (SUPPLIERS, PLANTS, MATERIALS, INVENTORY, PURCHASE_ORDERS, SHIPMENTS, DISRUPTIONS).
• Unstructured Repository: Staged PDF Master Service Agreements in @CONTRACTS_STAGE.
