ENTERPRISE CLOUD INFRASTRUCTURE

5-Tier Snowflake CoCo System Architecture

Built natively inside Snowflake's governed security perimeter to guarantee zero data egress and zero hallucination.

1. Presentation Layer
• Streamlit in Snowflake (SiS): SUPPLY_CHAIN_COMMAND_CENTER with live disruption heatmaps & 1-click PO rerouting.
• Snowflake CoCo CLI: Conversational terminal interface for planners, procurement teams, and logistics operators.
2. Action MCP Protocol
• FastAPI Action MCP Server: Implements supply_chain_mcp.py exposing 5 governed agentic actions.
• Transactional Tools: reroute_purchase_order, get_plant_stockout_risk, search_supplier_contracts.
3. Cortex Dual-Brain
• Snowflake Cortex Analyst: Semantic parser converting human intent into verified deterministic SQL queries.
• Snowflake Cortex Search: Vector search service (SUPPLIER_CONTRACTS_SEARCH) indexing PDF contracts & SLA clauses.
4. Governance & Dynamic Tables
• Semantic Ontology YAML: supply_chain_semantic_model.yaml defining trusted metrics, dimensions, and joins.
• 1-Minute Dynamic Tables: DT_PLANT_STOCKOUT_RISK, DT_SUPPLIER_PERFORMANCE, DT_ACTIVE_DISRUPTIONS.
5. Relational Foundation
• Core Schema: 7 relational tables in SUPPLY_CHAIN_DB.CORE (SUPPLIERS, PLANTS, MATERIALS, INVENTORY, PURCHASE_ORDERS, SHIPMENTS, DISRUPTIONS).
• Unstructured Repository: Staged PDF Master Service Agreements in @CONTRACTS_STAGE.
